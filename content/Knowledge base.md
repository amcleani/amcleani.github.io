# What is this?

This website contains a mini knowledge base consisting of short notes about topics related to my research and teaching. They link to one another, [[quantificationalism|like this]].

The notes you find here are selections from my personal knowledge base, built using [Obsidian](https://obsidian.md/). I use this database to keep my personal notes searchable, connected, and visualizable.  

This knowledge base is regularly being uploaded, as I write more notes and as I polish old ones into a shareable state. 

# Why is it here?

# How do I use it?

You can explore the knowledge base in three main ways. 

1. Follow clickable [[Quantificationalism|internal links]] in the main text. You'll find many of these across the website. 
2. Use the graph view on the top right of the screen (desktop) or at the very end of the page (tablet & mobile). 
	1. A *local graph* of the current page is always displayed, showing notes that can be reached from the current one by taking at most two steps. 
	2. A *global graph*, showing all notes, can be accessed by clicking on the little graph icon at the top right of the local graph view. 
3. Use backlinks. When you're on a note that some other note links to, you can see a list of notes that link to the current note on the bottom right of the screen (desktop) or at the very bottom of the page (tablet & mobile). These links can be clicked like internal links in the main text.
