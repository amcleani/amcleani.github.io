# Idea

*Filtration* is a construction for extracting finite countermodels from potentially infinite ones. Given a countermodel of a formula (or rule), filtration generates a finite countermodel  whose size is determined by the number of subformulas of the formula being refuted, which is always finite. 

# Definition

These definitions are dual to one another. 

## On modal algebras

Let $\struc{M}, \struc{N}$ be  modal algebras, $V,U$ valuations on $\mathfrak{M, N}$ respectively and $\Theta$ a set of formulae closed under subformulae. The pair $(\struc{N}, {U})$ is called a *filtration* of $(\struc{M}, U)$ *through* $\Theta$ when the following conditions hold:

1. There is a Boolean embedding $h\struc{N}\to \struc{M}$ whose range is precisely the Boolean subalgebra of $\struc{M}$ generated by $\{V(\varphi):\varphi\in \Theta\}$;
2. $V(\varphi)=U(\varphi)$ whenever $\varphi\in \Theta$
3. The embedding $h$ satisfies:
	1. $h(\square a)\leq \square h(a)$ for every $a\in N$;
	2. $h(\square a)= \square h(a)$  whenever $a=V(\varphi)$ and $\square\varphi\in \Theta$

## On modal spaces and Kripke frames

Let $\spa{X, Y}$ be modal spaces or Kripke frames,  $V,U$ valuations on $\mathfrak{X, Y}$ respectively and $\Theta$ a set of formulae closed under subformulae. We say that $(\spa{Y}, U)$ is a *filtration* of $(\spa{M}, U)$ *through* $\Theta$ when the following conditions hold: 

1. $\spa{Y}$ is (isomorphic to) the quotient of $\spa{X}$ generated by the equivalence relation $x\sim y$ iff $x$ and $y$ satisfy the same formulae from $\Theta$ in the model $(\spa{X}, V)$.
2. For all $x, y\in X$ we have
	1. If $Rxy$, then $R[x][y]$, where $[x]$ is the equivalence class of $x$ under $\sim$;
	2. If $R[x][y]$, then for any $\square\varphi\in \Theta$, if $\spa Y, V, y\not\models \varphi$, then $\spa X, V, x\not\models \square\varphi$.
